# Security Policy

## Supported Versions

Security updates are provided for the latest version of this repository on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in a project listed in this repository or within the repository itself, please report it responsibly.

For vulnerabilities affecting this repository, contact:

**Email:** abusofian.id@gmail.com

Please include the following information:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any relevant proof of concept or supporting information.

Please do not disclose security vulnerabilities publicly until they have been reviewed.

## Scope

This policy applies to:

- The Awesome Rust repository and its configuration.
- Documentation and contribution workflows maintained by this repository.

Security vulnerabilities in third-party projects listed here should be reported directly to their respective maintainers.
